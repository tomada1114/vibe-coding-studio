# Radiant デザインシステム完全ガイド

## 🎨 デザイン哲学

Radiantデザインシステムは、**「控えめな洗練」**、**「意図的なミニマリズム」**、**「動きで強化されたインタラクション」** の原則に基づいて構築されています。すべての要素は、どのフレームワークや技術スタックでも再現可能な、一貫性のあるビジュアル言語に従います。

---

## 🎯 いつ、何を使うべきか？（初心者向け決定ガイド）

### 迷ったときの基本ルール

1. **色で迷ったら** → グレーを使う（Gray-950 か White）
2. **余白で迷ったら** → 8の倍数を使う（8px, 16px, 24px, 32px）
3. **フォントサイズで迷ったら** → 16px（本文）か 24px（見出し）
4. **アニメーションで迷ったら** → 150ms ease-in-out
5. **影で迷ったら** → shadow-sm（ほとんど見えないくらい）
6. **角丸で迷ったら** → 8px（カード）か 完全な円（ボタン）

## 🎨 カラーシステム

### 基本哲学

- **モノクロベース**：グレースケールを主体とすることで、プロフェッショナルな洗練さを演出
- **最小限のアクセント**：色は控えめに使うことで最大のインパクトを生む
- **意味の明確さ**：各色には明確な機能的意味がある

## 📐 余白システム

### 基本単位

8pxグリッドシステム（必要に応じて4px単位の調整）

### 余白スケール

```
0.5: 2px   - 微調整のみ
1: 4px     - インライン間隔、小さなギャップ
1.5: 6px   - コンパクトな間隔
2: 8px     - 基本単位、最も一般的
2.5: 10px  - ボタンの垂直パディング
3: 12px    - モバイルでのカードパディング
4: 16px    - 標準的なギャップ、ボタンの水平パディング
5: 20px    - モバイルのセクション間隔
6: 24px    - コンポーネント間隔
8: 32px    - デスクトップのセクションパディング
10: 40px   - 大きな間隔
12: 48px   - ヒーローセクション
16: 64px   - 主要セクション
20: 80px   - ページレベルの間隔
24: 96px   - 特大の間隔
32: 128px  - 最大間隔
```

### どこでどの余白を使うか？

#### 場面別余白選択ガイド

| 場所                   | 使用する余白                  | 理由                   |
| ---------------------- | ----------------------------- | ---------------------- |
| ボタン内のテキスト周り | 横16px、縦10px                | 押しやすいサイズを確保 |
| カード内のコンテンツ   | 24px（モバイル）/ 32px（PC）  | 読みやすさと高級感     |
| セクション間           | 80px（モバイル）/ 128px（PC） | 明確な区切り           |
| 段落間                 | 24px                          | 読みやすいリズム       |
| リスト項目間           | 16px                          | 関連性を保ちつつ区別   |
| アイコンとテキスト間   | 8px                           | 視覚的な繋がり         |
| ページの左右余白       | 24px（モバイル）/ 32px（PC）  | 画面端からの適切な距離 |

## 🔲 コンポーネントパターン

### ボタン - いつ使うか？

#### ボタンタイプ選択ガイド

| 状況                   | 使用するボタン          | 例                     |
| ---------------------- | ----------------------- | ---------------------- |
| 最も重要なアクション   | Primary（黒背景）       | 「購入する」「送信」   |

#### Primary ボタン仕様

```

角丸: 完全な円（rounded-full）
色: 背景Gray-950、文字White、ホバー時Gray-800
フォーカス: 2pxリング、2pxオフセット、Gray-950
```

## 🎭 モーションとアニメーション

### アニメーション速度の選び方

#### 速度選択ガイド

| 状況                 | 使用する速度 | 具体例                   |
| -------------------- | ------------ | ------------------------ |
| ボタンを押した瞬間   | 75ms         | active状態               |
| ホバー効果           | 150ms        | 色の変化、影の変化       |
| 要素の表示/非表示    | 200ms        | ドロップダウン、モーダル |
| ページ遷移           | 300ms        | フェードイン、スライド   |
| 複雑なアニメーション | 500ms        | ローディング、プログレス |

### イージング関数の選び方

```
ease-in-out（デフォルト）: ほとんどのトランジション
ease-out（減速）: 要素が現れるとき
ease-in（加速）: 要素が消えるとき
cubic-bezier(0.34, 1.56, 0.64, 1)（バウンス）: 遊び心のあるフィードバック
```

## 🔧 よくある間違いと解決法

### ❌ 避けるべきこと → ✅ 正しい方法

1. **色を使いすぎる** → グレースケールで十分
2. **影を濃くする** → ほとんど見えないくらいが正解
3. **余白をランダムにする** → 8の倍数を厳守
4. **アニメーションを派手にする** → 控えめで高速に
5. **角を尖らせる** → 最低4px、通常8pxの角丸
6. **ボーダーを太くする** → 1pxで十分
7. **フォントを増やす** → システムフォントで統一
8. **青いリンク** → 親要素と同じ色に

## 💡 デザイン決定フローチャート

### 新しい要素を作るとき

1. **既存のコンポーネントで代用できるか？**
   - Yes → 既存のものを使う
   - No → 次へ

2. **本当に必要か？**
   - No → 作らない
   - Yes → 次へ

3. **色は必要か？**
   - No → Gray-950/Whiteのみ
   - Yes → 本当に？ → それでも必要なら最小限に

4. **動きは必要か？**
   - No → 静的に
   - Yes → 150ms ease-in-out

5. **装飾は必要か？**
   - No → そのまま
   - Yes → 本当に？ → shadow-smだけ

---

このガイドに従えば、デザイン経験がなくても、Radiantデザインシステムを完璧に再現できます。迷ったときは、「より少なく、よりシンプルに」を選択してください。
