## コースの説明文

「CLAUDE.mdにルールを書きすぎて、コンテキストがパンパンになってしまった...」

「サブエージェントとかSkillsとかHooksとか、結局どれを使えばいいの？」

「公式ドキュメントを読んでもよく分からない...実践的な使い分けを知りたい」

そんなClaude Codeユーザーの悩みを、本講座で一気に解決しましょう！

Claude Codeには「CLAUDE.md」「.claude/rules/」「カスタムコマンド」「サブエージェント」「Skills」「Hooks」という6つのカスタマイズ機能があります。これらを使いこなせば、コンテキストを節約しながら、あなただけの「専用AIアシスタント」を構築できます。

本講座では、シンプルな機能から段階的に学び、各機能の本質的な違いと適切な使い分けを完全にマスターします。

【講座の特徴】

1. 6つのカスタマイズ機能を「2つの軸」で整理して完全理解
   - 「いつ読み込まれるか」と「誰が動くか」という2つの軸で整理
   - 機能比較マトリクスと判断フローチャートで迷わない
   - コンビニ店員アナロジーで直感的に理解できる
   - 公式ドキュメントだけでは分かりにくい実践的なノウハウ

2. 「シンプル→複雑」の順番で無理なく学べる
   - CLAUDE.md（土台）→ rules（モジュール化）→ コマンド → サブエージェント → Skills → Hooks
   - 各機能の関係性を理解しながら段階的にステップアップ
   - 「確率論的 vs 決定論的」など、機能の本質的な違いを理解
   - 前のセクションの知識が後のセクションの理解に役立つ構成

3. コンテキスト節約の観点から各機能を徹底解説
   - CLAUDE.mdの肥大化問題とその解決策
   - rulesによる動的読み込みでトークン消費を最小化
   - Skillsの「レシピ本」アナロジーで段階的読み込みを理解
   - サブエージェントによる独立コンテキストの活用法

4. 実践的なデモと豊富な実例
   - 各機能の実際の作成手順をデモで確認
   - /agentsコマンドでのサブエージェント作成
   - skill-creatorプラグインでのSkill作成
   - Hooksによる自動フォーマット設定

【こんな方におすすめ】

■ Claude Codeをもっと効率的に使いこなしたい方
- 基本的なバイブコーディングはできるようになった
- コンテキストの圧迫が気になっている
- 毎回同じプロンプトを入力するのが面倒
- 最新の拡張機能を習得したい

■ CLAUDE.mdの管理に困っている方
- ルールを書きすぎてファイルが肥大化している
- 関係ないルールまで読み込まれて効率が悪い
- ルールの整理・分割方法を知りたい
- コンテキスト消費を抑えたい

■ 6つの機能の使い分けが分からない方
- rulesとCLAUDE.mdの違いが分からない
- サブエージェントとSkillsの使い分けが分からない
- Hooksをいつ使えばいいか分からない
- 公式ドキュメントを読んでも理解できなかった

■ 開発効率を上げたい個人開発者・フリーランス
- 繰り返し作業を自動化したい
- プロジェクトごとに最適化されたAI環境を作りたい
- チームでルールを共有したい

【本講座で学べる内容】

1. カスタマイズ機能の全体像
   - 6つの機能を「いつ読み込まれるか」「誰が動くか」で整理
   - どの機能をいつ使うべきか判断フローチャート
   - コンビニ店員アナロジーで直感的に理解
   - 公式ドキュメントの読み方

2. CLAUDE.md - プロジェクト知識の土台
   - CLAUDE.mdの本質的な役割と仕組み
   - メモリ階層（5段階の優先順位）
   - 効果的なルールの書き方（具体的 vs 曖昧）
   - /initコマンドによる作成

3. .claude/rules/ によるルールのモジュール化
   - CLAUDE.md肥大化問題の解決策
   - pathsフィールドによる動的読み込み
   - Globパターンの書き方
   - 条件付きルール適用の実践

4. カスタムコマンドの作成と活用
   - プロンプトのショートカット化
   - YAMLフロントマター（description, allowed-tools等）
   - 引数パターン（$ARGUMENTS vs $1/$2/$3）
   - @プレフィックス（ファイル参照）と!プレフィックス（Bash実行）

5. サブエージェント - 独立コンテキストの活用
   - メインエージェントとの違い（コンテキスト独立）
   - YAMLフロントマター（name, description, tools等）
   - /agentsコマンドによる作成
   - 発動しないときの改善方法（PROACTIVELYキーワード等）

6. Skills - 動的知識の読み込み
   - 「レシピ本」アナロジーで理解する段階的読み込み
   - Progressive Disclosure（3層構造）
   - SKILL.mdの基本構造とdescriptionの書き方
   - reference.md / examples.md / scripts/ の活用

7. Hooks - 決定論的な自動化
   - 確率論的（CLAUDE.md）vs 決定論的（Hooks）の違い
   - 10種類のフックイベント（PreToolUse, PostToolUse, Stop等）
   - settings.jsonでの設定方法
   - マッチャーの基本パターン

【学習の進め方】

本講座は、シンプルな機能から複雑な機能へ段階的に学ぶ構成です。

まずセクション2で6つの機能の全体像を把握し、その後セクション3〜8で各機能を個別に習得していきます。

各セクションには実践的なデモを含んでいるので、実際に手を動かしながら学べます。

Claudeのサブスクリプション（ProまたはMax）があれば、追加費用なしで全ての機能を使えます。

バイブコーディングの次のステップへ、一緒に進みましょう！
