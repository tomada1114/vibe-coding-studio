## 学習の目標

本章では、以下の内容を学習します。

- Git の基本的な概念と役割を理解する

## はじめに

ここからの作業では、変更内容を後で追えるようにするため、ソースコードを **GitHub** で管理していきます。Git や GitHub アカウントの設定などが済んでいる方は、techlog-app 用のリモートリポジトリを GitHub に作成するだけで先に進んでも構いません。

まだ Git や GitHub について詳しくない方のために、基本的な概念から説明していきます。

## Git とは？

Git は**ファイルのバージョン（履歴）を管理するシステム**です。ソースコードを変更する開発を進めていると、変更しすぎて正常に動作しなくなってしまうことがあります。

こういった時に役立つのが、正常に動作していた途中の状態を一つのバージョンとして保存しておき、後で復元できる機能を持つ Git です。これにより、「前の状態に戻す」という操作が簡単にできるようになります。

Git の主な利点は次のようなものです。

- 変更履歴を記録し、いつでも以前のバージョンに戻れる
- 複数の開発者が同時に作業できる
- 変更内容を明確に把握できる
- ブランチを使って実験的な機能を安全に開発できる

Git は個人で開発する際に役立つのはもちろん、ソースコードのバージョンを細かく他の人に共有することができるため、チームでの開発をする時に活躍します。

今やどの開発現場においても Git を使うことは当たり前のようになっていますが、未経験からエンジニアとなった方がつまずきやすいポイントでもあります。この機会にしっかりと使いこなし、エンジニアの一歩を踏み出していきましょう。

## GitHub とは？

**GitHub** は、Git を用いてバージョン管理されたソースコードを共有するためのプラットフォームです。Git では **リポジトリ** と呼ばれる箱のようなものでソースコードを管理していきます。

自分のパソコン上で作成したリポジトリ（ローカルリポジトリ）を、GitHub というオンライン上のリポジトリ（リモートリポジトリ）にアップロードしておくことで、以下のようなことが可能になります。

- チームメンバーがコードを閲覧・編集できる
- コードレビューを行える
- プルリクエストを使った協働開発ができる
- AWS や Heroku といった外部サービスと連携して、アプリケーションをデプロイできる

## 初期設定・リモートリポジトリ作成

まずは GitHub にリモートリポジトリを作成し、SSH の設定を行いましょう。以下の手順でアカウント作成からリポジトリ設定までを完了させます。

### 【注意点】

- 「GitHub に SSH の設定をする」まで完了させ、「GitHub にプッシュをする」には **進まず** に止めておいてください。
- リポジトリは Private ではなく Public に設定しておくことをおすすめします。
- `ssh-keygen -t ed25519 -C "GitHubに登録したメールアドレス"` といったコマンドを実行した後に設定するパスワードは今後も使うものですので、覚えておきましょう。

### リモートリポジトリの作成

リモートリポジトリを作成するときは、以下のような設定にしましょう。リポジトリ名は **techlog-app** にしてください。

![GitHub リポジトリ作成画面](/img/rails/github-repository-create.png)

リモートリポジトリを作成した後は、以下のような画面が GitHub では表示されているはずです。

![GitHub リポジトリ作成完了画面](/img/rails/github-repository-created.png)

画像のうち、赤枠で囲った部分に表示されている以下コマンドについては、後ほど使うのでメモしておいてください（アカウント名はそれぞれ異なります）。

```bash
git remote add origin https://github.com/アカウント名/techlog-app.git

git branch -M main

git push -u origin main
```

これらのコマンドは、ローカルリポジトリを GitHub のリモートリポジトリに接続するために使用します。詳細は次の章で説明します。

## まとめ

本章では、Git と GitHub の基本概念について学び、GitHub アカウントの作成からリモートリポジトリの設定までを行いました。具体的には以下の内容を学習しました。

- Git はファイルのバージョン管理システムであり、開発の履歴を記録する
- GitHub は Git リポジトリをオンラインで共有するプラットフォーム
- リモートリポジトリを作成することで、複数人での開発やコード共有が容易になる
- SSH キーを設定することで、安全にリモートリポジトリと通信できる

次の章では、作成したリモートリポジトリと TechLog アプリを連携させ、実際にソースコードをアップロードする方法を学びます。
