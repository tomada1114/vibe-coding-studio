## 学習の目標

本章では、Windowsパソコンに`Ruby`をインストールする方法を学びます。プログラミングを始める上で最初の壁となるのが開発環境の構築です。まずはRubyを正しくインストールして、プログラミングができる状態を整えましょう。

## はじめに

プログラミングを始めるには、まず開発環境を整える必要があります。本章では、Windowsパソコンに`Ruby`をインストールする手順を、できるだけ丁寧に解説していきます。

Windowsでのインストールは画面の操作が多いため、各ステップごとに詳しく説明していきます。

## Step 1: システム情報の確認

**適切なバージョンのRubyを選択するために**、まずパソコンのシステム情報を確認します。特に重要なのは、お使いのパソコンが32ビットか64ビットかを確認することです。

以下の手順で確認してください。

1. キーボードの`Windowsキー（⊞）`を押しながら`I`キーを押します
2. 表示された設定画面で`システム`をクリックします
3. `バージョン情報`を開きます
4. `システムの種類`の項目を確認します（**32ビットか64ビットかを確認**）

32ビットか64ビットかを確認した結果は次のステップで必要となりますので、メモを取っておいてください。

## Step 2: Rubyのダウンロード

続いて、Rubyのインストーラーをダウンロードします。Windowsでは、「RubyInstaller」というツールを使ってRubyをインストールするのが一般的です。

まず、Webブラウザで`RubyInstaller`の公式サイトにアクセスします。

[https://rubyinstaller.org/downloads/](https://rubyinstaller.org/downloads/)

次に **WITH DEVKIT**セクションから、適切なバージョンを選択します。

![Windowsインストーラー](/img/ruby/windows-ruby-installer.png)

本記事の執筆時点では、以下のバージョンが最新ですが、時期によって異なる場合がありますので、最新のものを選択してください。

- **64ビットシステムの場合：**`Ruby+Devkit 3.4.1-1 (x64)`を選択
- **32ビットシステムの場合：**`Ruby+Devkit 3.4.1-1 (x86)`を選択

ご自身のパソコンのシステム情報に合わせて、適切なバージョンを選択し、インストーラーをダウンロードしてください。

## Step 3: インストール手順

ダウンロードしたインストーラーを使用して、実際にRubyをインストールしていきます。インストール中に複数の選択肢が表示されますが、基本的に推奨設定のままで問題ありません。

**基本的なインストール手順：**

1. ダウンロードしたファイルをダブルクリックして実行します
   - ファイル名は「rubyinstaller-devkit-3.4.1-1-x64.exe」のような形式です（バージョンと環境により異なります）

2. 表示される画面で以下の選択を行います。
   - `Install for me only`を選択
   - `I accept the License`にチェックを入れる
   - `Next`ボタンをクリック
   - 続いて`Install`ボタンをクリック

※選択項目は画面によって異なる場合がありますので、異なる場合は推奨設定のまま進めてください。

### MSYS2のインストール

Rubyのインストールが完了すると、自動的にコマンドプロンプト（黒い画面）が開きます。これは、Rubyで使用する追加コンポーネント「MSYS2」のインストール画面です。

画面の指示に従ってインストールを進めていきます。

以下は一例ですが、実際の画面は異なる場合がありますので、注意してください。

1. キーボードで`1`を入力し、`Enter`キーを押す
2. 続いて`3`を入力し、`Enter`キーを押す
3. 最後に`Enter`キーを押してインストールを完了する

## Step 4: インストールの確認

正しくインストールできたか確認するために、以下の手順を実行します。ここでは、インストールされたRubyのバージョンを確認します。

**バージョン確認手順：**

1. `Windowsキー（⊞）`を押しながら`R`キーを押します
2. 表示された画面で`cmd`と入力し、`Enter`キーを押します
3. 開いたコマンドプロンプト（黒い画面）で以下のコマンドを入力し、`Enter`キーを押します

```
ruby -v
```

バージョン情報が表示されれば、インストールは成功です。例えば、以下のような表示が出ればOKです。

```
ruby 3.4.1p0 (2024-03-12 revision 5a03f8c590) [x64-mingw-ucrt]
```

## Rubyプログラムを動かしてみよう

Rubyが正しくインストールできたかを確認するため、簡単なRubyプログラムを実行してみましょう。

1. コマンドプロンプトで以下のコマンドを入力し、`Enter`キーを押します

```
ruby -e "puts 'Hello, Ruby World!'"
```

「Hello, Ruby World!」と表示されれば、Rubyが正常に動作しています。
