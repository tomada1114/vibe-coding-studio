## 実装の進め方

### 推奨実装順序
1. **タスク1（定数管理）**: すべてのページで使用する定数を最初に実装
2. **タスク2-3（トップページ）**: トップページのコア機能とフッター拡張を実装
3. **タスク4-11（コミュニティページ）**: コミュニティページの各セクションを順次実装
4. **タスク12-13（テスト）**: 実装完了後にユニットテスト、コンポーネントテスト、E2Eテストを実行
5. **タスク14-15（品質検証）**: 型安全性、コード品質、パフォーマンスを最終確認

### 実装時の注意点
- 各タスク完了後、動作確認とテストを実行
- コミット前に`npm run pre-commit-check`を実行
- 既存のRadiantテンプレートコンポーネントを最大限活用
- TypeScript厳格モードを遵守し、`any`型を使用しない
- Tailwind CSS v4のユーティリティクラスを使用
- レスポンシブデザインを常に意識

### タスク完了の定義
- 機能が要件通りに動作する
- TypeScript型エラーがない
- ESLintエラーがない
- 関連するテストが合格する
- コードレビューが完了している（チームの場合）
