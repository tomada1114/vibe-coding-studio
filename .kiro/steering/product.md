# Vibe Coding Studio - Product Overview

**Inclusion Mode**: Always

---

## Product Overview

Vibe Coding Studio は、Next.js 15 と Tailwind CSS v4 を使用したモダンな静的サイトです。Tailwind Plus の Radiant サイトテンプレートをベースに、CMS や認証システムなどの外部依存関係を排除し、クリーンで静的なサイト基盤として構築されています。

エンタープライズグレードのセキュリティ機能、パフォーマンス最適化、包括的なコンポーネントライブラリを備えた、本番環境対応のテンプレートです。

## Core Features

### 開発体験
- **Next.js 15 App Router**: 最新のReactフレームワークによる高速開発
- **TypeScript厳格モード**: 型安全性の確保とバグの早期発見
- **Tailwind CSS v4**: PostCSSによる最新のユーティリティファーストスタイリング
- **Hot Module Replacement**: 高速な開発サーバーによる即座のフィードバック

### UIコンポーネント
- **Headless UI**: アクセシブルなコンポーネント基盤
- **Framer Motion**: スムーズなアニメーション
- **Catalyst UI統合**: エンタープライズグレードのUIコンポーネント
- **カスタムコンポーネントライブラリ**: 50以上の再利用可能なコンポーネント

### セキュリティ
- **Content Security Policy (CSP)**: nonceベースのインラインスクリプト実行
- **セキュリティヘッダー**: HSTS、X-Frame-Options、Permissions-Policy
- **CSP違反レポート**: `/api/csp-report` エンドポイント
- **エッジランタイム対応**: Web Crypto APIを使用した安全な実装

### パフォーマンス
- **Incremental Static Regeneration (ISR)**: 60秒の再検証によるキャッシュ最適化
- **画像最適化**: AVIF/WebP サポート
- **バンドル分析**: サイズ最適化のための分析ツール
- **ミドルウェアキャッシュ**: 詳細なキャッシュ戦略

### 品質保証
- **Jest単体テスト**: コアコンポーネントの完全なカバレッジ
- **ESLint**: コード品質チェック
- **Prettier**: 一貫したコードフォーマット
- **TypeScript型チェック**: 厳密な型検証
